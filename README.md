# NeuroScan PACS — Clinical Brain MRI Analysis & AI Review Workbench

A clinical-style web workbench for reviewing brain MRI scans, calculating real pixel radiomics, running K-means unsupervised tissue segmentation, and performing preliminary AI-assisted radiological reviews using Google's multimodal **Gemini Flash** models.

## Repository Structure
- `index.html` — Modular PACS viewer interface and clinical controls
- `app.js` — Radiomics engine, DICOM viewport, and Gemini multimodal pipeline
- `ai-lab.js` — K-means clustering and rule-based expert system
- `README.md` — Project documentation
